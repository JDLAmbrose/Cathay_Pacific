# Plume Light 多頁前端演示

本版以 `doc/Plume_Light_PRD.md` 1.3 為基礎，使用純 HTML、CSS 與 JavaScript，無建置或第三方網路依賴。

## 開啟方式

可直接開啟專案中的 `index.html`。若瀏覽器限制本地檔案的儲存功能，請在專案目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000/`。所有演示頁面應使用同一網址來源，以共享行李與訂單狀態。

## 頁面

根目錄僅保留 `index.html` 一個入口檔案。功能頁面集中在 `pages/`，舊版原型保存在 `archive/`，輔助腳本保存在 `tools/`。分享時請保留 `index.html`、`assets/` 與 `pages/` 的相對位置。

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 行程首頁、航班橫幅、功能入口、三組案例輪播 |
| `pages/prepare.html` | 實際乘機人、家人在家協助填寫、聯絡資料 |
| `pages/baggage.html` | 全部托運行李預報、服務行李選擇、尺寸與重量 |
| `pages/rules.html` | 五步流程中的 AI 攜帶規則諮詢 |
| `pages/delivery.html` | 收取地區、申請截止、首末程安排 |
| `pages/checkout.html` | 費用明細、現金或里數模擬結算 |
| `pages/assistant.html` | 可從主導覽直接進入的 AI 出行助手 |
| `pages/journey.html` | 訂單、退款、三類交接節點及事件演示 |
| `pages/operations.html` | 已保存預報彙總、重量與空間規劃、演示參數 |
| `archive/index-original.html` | 原始 UI 設計，獨立保留 |
| `archive/index-prd-single.html` | 本次拆頁前的 PRD 1.3 單頁原型，獨立保留 |

## 共用程式

- `assets/i18n.js`：繁體中文、英語、法語、西班牙語與阿拉伯語完整文案。`t(key, args)` 處理變數；新增文案時五欄皆須填妥。使用者自行輸入的姓名、地址或問題原文保留，不自動翻譯。固定品牌、機場代碼與 `LSE Student Dormitory 6` 保留。
- `assets/model.js`：行李彙總、未知值處理、截止校驗、報價、里數支付、交接、退款及確定性 AI 規則樣本。
- `assets/app.js`：共用頁首、航班橫幅、頁面渲染、表單事件及實際連結跳轉。
- `assets/styles.css`：響應式設計、邏輯方向屬性、大字模式及減少動畫偏好。

原型資料儲存鍵為 `plume-light-multipage-v2`，與前一單頁版本分開。語言儲存鍵為 `plume-light-language`，跨頁保留；阿拉伯語設定 `dir="rtl"`。未提交的表單及問題草稿可跨頁保留；營運看板只統計已保存預報。

## 120 秒演示建議

1. 首頁展示 CX257 香港至倫敦希思羅 T3、LSE Student Dormitory 6 與保留的飛行進度橫幅；右上角切換語言。
2. 進入行李準備，將首件行李由 20 kg 改為 30 kg 並保存；營運頁總重由 1800 kg 改為 1810 kg，規劃餘量由 1700 kg 改為 1690 kg。
3. 助手詢問充電寶，追問後輸入 `74 Wh`；查看樣本來源，確認後回寫清單。結果不是承運批准。
4. 收取地區切換香港、大灣區及內地，查看 24 / 48 / 120 小時截止；預設香港取件。
5. 預設現金 HKD 1600、預計賺取 160 里數；可切換為 40000 里數兌換。選定一種方式模擬支付，跳至行程頁。
6. 開啟交接事件控制，依序確認到機場、部分裝機、全部裝機、倫敦物流交接。只有三類節點；內部服務完成後現金訂單才入帳里數。
7. 返回首頁，以按鈕、圓點、鍵盤或觸控左右滑動查看留學生、兒童、輪椅使用者三個案例。

頁尾演示控制台可重設留學生、兒童家庭、超時及缺少尺寸等狀態。所有資料與交易為模擬，沒有接入真實航空公司、支付、會員、物流或官方規則檢索。三個案例的人物、成功情境及引述均為創作，不是真實客戶見證。

## 變更原則

保留全部托運需求與購買服務需求的區分；同一乘機人及航段只計最新有效申報。未知值不得轉成零。飛行進度不推動行李交接，付款不等於裝機。行李預約亦不表示兒童乘機、無障礙協助或設備承運獲批。新增真實後端時，截止時間、支付冪等性、會員帳本與承運確認應由服務端執行。


## 首頁與問答擴充

頂部品牌列僅顯示 CATHAY PACIFIC 與 Plume Light；航班橫幅刪除額外的時刻提示列。案例卡片以編號取代「演示資料」徽章，並使用本地人物照片配圖。三個案例仍為虛構情境；配圖由內建 image_gen 生成，完整提示詞見 `doc/IMAGE_ASSETS.md`。

- 留學生：香港 → CX257 → 倫敦希思羅 T3 → LSE Student Dormitory 6。
- 兒童：深圳家中取件 → 香港機場 → CX105 → 澳洲墨爾本 → 父母住所。
- 佐藤陽翔 Haruto Sato：日本研究學者完成香港學術交流 → CX580 香港 → CTS 札幌新千歲 → 北海道住所。

案例路線不會改動預設訂單的 CX257 航班，也不會把倫敦報價套用到墨爾本或札幌。

AI 演示目前有 13 類問題：衣物書籍、電池、輔助設備、液體、藥品、食品、電子與易碎品、申請截止、價格、里數、交接狀態、家人協助及配送安排。液體、藥品、食品與電池可先追問屬性，並提供一鍵範例回覆。服務費用與里數按當前選擇的行李計算，保存答案快照；資料變更時答案會標記待更新。所有介面文案與預設回答提供五種語言。

英國、澳洲與印度提供有限的模擬規則樣本，並顯示對應來源範圍；法國仍用作未覆蓋目的地示例。查詢其他目的地不會改簽，也不能把其他航線建議寫回 CX257 清單。來源缺失、過期、衝突與未覆蓋物品仍維持待確認。這不是已接入的 AI Agent，也不提供實際承運或入境批准。


## 案例輪播更新

人物照片保留 PLUME LIGHT 與案例編號，不再顯示留學生、無人陪伴兒童或殘障人士的分類徽章。人物簡介採用姓名、年齡及旅程背景；協助需求仍在故事內自然說明。第三位人物為日本研究學者佐藤陽翔 Haruto Sato，搭乘 CX580 由香港至札幌新千歲 CTS。

進入案例區域後，每 8 秒自動輪播並循環回第一張。滑鼠懸停、鍵盤聚焦閱讀、頁面隱藏或案例離開可視區時暫停；不顯示播放／暫停按鈕；可使用左右箭頭、圓點、觸控螢幕或觸控板橫向手勢切換。語言切換後仍只保留一個計時器。實作間隔設定為 `STORY_INTERVAL_MS = 8000`。


### 觸控板手勢

案例區域支援雙指橫向滑動，採用累積位移門檻與手勢結束後的重設：一次持續的滑動及其慣性只切換一張，反向的新手勢可切回。縱向及以縱向為主的斜向滾動仍交由頁面處理；不攔截縮放手勢。阿拉伯語維持對應的方向語意。每 8 秒的自動輪播與懸停、鍵盤閱讀暫停繼續保留。
