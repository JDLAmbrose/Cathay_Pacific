| 场景                      | v2.1 时长  | **v2.2 时长** | 调整原因              |
| ----------------------- | -------- | ----------- | ----------------- |
| 1. Mission Impossible   | 8s       | **8s**      | 保持戏剧性开场           |
| 2. 行李大作战                | 10s      | **10s**     | 保持痛点共鸣            |

| 4. 轻松启程                 | 16s      | **12s**     | 精简家庭协助细节          |
| 5. 智能申报                 | 18s      | **14s**     | 精简地区规则展示          |
| **6. AI小助手**            | **20s**  | **12s**     | **只展示核心功能**       |
| 7. 航司商业价值               | 20s      | **20s**     | 保持完整对比叙事          |
| 8. Mission Accomplished | 14s      | **14s**     | 保持callback        |
| **9. 多元客群**             | **8s**   | **12s**     | **独立分镜，充分展示前后对比** |
| **10. 品牌定格**            | **8s**   | **12s**     | **独立分镜，强化品牌记忆**   |
| **总计**                  | **120s** | **120s**    | **严格保持总时长**       |

### 🎯 调整原则

1. **AI助手不是重点** → 只保留"提问→追问→三层回答→回写"的核心流程，删减细节展示
2. **多元客群需要充分展示** → 12秒足够做3组客群的**完整前后对比**（每组3-4秒）
3. **品牌定格值得更多时间** → 12秒可以让观众**充分阅读**品牌信息，形成记忆点
4. **从场景4、5匀出时间** → 这两处可以更紧凑，不影响核心信息传达
