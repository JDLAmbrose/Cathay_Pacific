# Cathay_Pacific
All for Cathay Hackathon 


## 分享與開啟

雙擊根目錄的 `index.html` 開啟網站。分享時請一併傳送整個網站資料夾，或使用分享版壓縮包；接收者解壓後再開啟 `index.html`。

網站運作需要 `index.html`、`assets/` 和 `pages/`，請保留它們的相對位置。分享版僅包含這些執行檔案及本說明；完整專案另外保留文件、歷史版本與輔助腳本。

- `index.html`：唯一主入口。
- `pages/`：預訂、助手、行程及營運等功能頁面。
- `assets/`：共用程式、樣式與圖片。
- `doc/`：需求、分鏡與使用說明。
- `archive/`：保留的舊版原型。
- `tools/`：原有輔助腳本。

若瀏覽器限制本地檔案的儲存功能，可在網站根目錄執行 `python3 -m http.server 8000`，然後瀏覽 `http://localhost:8000/`。

此網站為概念演示，預訂、付款與物流資料均為模擬資料。
