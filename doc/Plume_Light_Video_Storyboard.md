## 🎨 视觉风格指南

### 手绘插画部分

**画风参考**：

- 异想天开的手绘拼接风格，可以部分参考《纽约客》 editorial illustration 
- 线条略带抖动感（模拟真实手绘）
- 色彩：温暖的大地色系 + 国泰品牌绿松石色作为点缀
- 人物造型：Q版2头身，夸张表情（尤其眼睛和嘴巴）
- 背景：简洁线条，不抢戏

**调色板**：

```css
--skin-tone: #F5DEB3;
--hair-color: #2C1810;
--clothing-primary: #4A90E2; /* Lin的蓝色外套 */
--clothing-secondary: #E74C3C; /* 行李箱红色 */
--accent-cathay: #006564; /* 国泰绿松石 */
--background-warm: #FFF8E7; /* 暖色背景 */
--shadow: rgba(0,0,0,0.1);
```

**动画原则**：

- 使用"弹性缓动"（ease-out elastic）让动作更有生命力
- 夸张物理效果（行李弹跳、人物踉跄）
- 适当使用"漫画式速度线"表现速度或冲击

### UI演示部分

- 保持原有index.html的设计语言
- 在手绘场景转入时，使用"纸张翻转"或"墨水晕染"过渡
- 光标移动要有"思考停顿"（人类操作的自然节奏）

## ⏱️ 附录：时间分配 rationale（设计思路）

### 为什么场景1给18秒？

**原因**：建立情感共鸣需要时间

- 00-08秒：建立场景（房间、行李、混乱）
- 08-15秒：升级冲突（机场、问题爆发）
- 15-18秒：情感留白（低谷，为"救星"做铺垫）

如果太快（比如压缩到10秒），观众还没感受到Lin的困境，Plume Light的出现就会显得突兀。

### 为什么场景5（AI Agent）给20秒？

**原因**：这是技术亮点，需要充分展示

- 00-05秒：用户提问
- 05-10秒：AI追问（体现智能）
- 10-15秒：三层回答（核心价值）
- 15-18秒：建议回写（强调用户控制权）
- 18-20秒：理解留白

AI Agent是差异化功能，不能草草带过。

### 留白时间的分布

| 位置           | 时长 | 目的         |
| ------------ | -- | ---------- |
| 场景1结尾        | 3s | 情感沉淀       |
| 场景3 family部分 | 2s | 理解"远程协助"价值 |
| 场景4 地区规则     | 3s | 理解智能逻辑     |
| 场景5 AI思考     | 2s | 制造期待感      |
| 场景5 结论展示     | 2s | 阅读信息       |
| 场景5 决策前      | 2s | 强调用户控制权    |
| 场景6 数据联动     | 3s | 观察连锁反应     |
| 场景7 支付选择     | 2s | 对比两种方式     |

**总计留白：约19秒（占总时长16%）**

这个比例符合现代短视频的节奏——既不过于紧凑让人喘不过气，也不拖沓失去注意力。

## 🎬 附录：录制与制作注意事项

### 录制前的准备

1. **UI状态预置**
   - 提前在index.html中配置好所有演示数据
   - 使用`resetDemo()`函数确保每次录制起始状态一致
   - 截图保存每个场景的"初始状态"作为备份
2. **光标路径规划**
   - 使用工具录制光标轨迹（或手动编写坐标序列）
   - 每个"点击"前必须有0.3-0.5秒的"移动时间"（模拟真人操作）
   - 避免"瞬移"——那会破坏沉浸感
3. **音频录制**
   - 优先使用真人配音（情感更自然）
   - 如果用TTS，需要在`timeline.js`中调整`tts`字段
   - 背景音乐音量控制在-20dB（不要盖过旁白）

### 录制中的节奏控制

**常见错误**：

- ❌ 操作太快（观众跟不上）
- ❌ 没有停顿（像快进的视频）
- ❌ 音画不同步（口型对不上）

**正确做法**：

- ✅ 每个操作后停顿0.5-1秒（让观众消化）
- ✅ 重要信息重复两次（视觉+听觉）
- ✅ 使用`timing.js`中的精确时长对齐

### 后期制作

1. **手绘素材合成**
   - 使用AI图像生成工具（如Midjourney/DALL-E）生成基础素材
   - 在After Effects/Figma中添加动画
   - 导出为透明背景的MOV（便于叠加到UI录屏上）
2. **转场特效**
   - 使用Premiere Pro / DaVinci Resolve的转场插件
   - 保持转场时长一致（0.6秒，前后各0.3秒）
   - 避免使用过于花哨的转场（分散注意力）
3. **字幕与标注**
   - 字体：Noto Sans SC（中文）/ Inter（英文）
   - 关键数字用**粗体**高亮
   - 品牌术语（Plume Light、CX257等）保持英文原文

### 质量检查清单

- [ ] 总时长是否严格控制在120秒（±1秒可接受）
- [ ] 手绘风格和UI风格过渡是否自然
- [ ] 所有数据是否与PRD一致（CX257、60kg、HKD 1600等）
- [ ] 旁白是否清晰、情感是否到位
- [ ] 留白时间是否足够（不被背景音乐填满）
- [ ] 免责声明是否完整（演示数据、拟合作示例等）
- [ ] 国泰品牌元素是否正确（logo、配色、术语）
